Notes
-----
* The pipeline otherwise requires only base R packages (stats, graphics,
  grDevices, parallel).
* org.Hs.eg.db is NOT used: gene identifiers are mapped with the NCBI
  Homo_sapiens.gene_info table, whose Entrez-to-symbol and Ensembl-to-symbol
  maps are cached by 01_prep.R.
* effsize is NOT used: the Cohen's d reported in fig7 is computed directly,
  with Hedges' correction applied by hand.
* CIBERSORT and LM22 are NOT used by any script in this repository.
  Signature-matrix deconvolution was evaluated and rejected during method
  development (see docs/PIPELINE.md, "Rejected approach"); fig7 reports a
  marker-gene panel instead.
* On Windows, parallel::mclapply is unavailable; any parallelism must use
  parallel::makeCluster(type = "PSOCK").
